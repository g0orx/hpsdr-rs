QO-100 demo

hpsdr-rs — receiving the QO-100 narrowband transponder

An MSI.SDR stick behind a 10 GHz LNB, set up as a transverter (Settings → XVTR) so the dial reads the real downlink frequency. The PSK Beacon panel is decoding the transponder's 400 bit/s middle beacon, and Lock LNB is using it to correct the LNB's frequency drift live.
